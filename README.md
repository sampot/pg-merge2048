# pg-merge2048

瀏覽器**數字合併**（2048）：滑格同數合併、挑戰 2048、本機最高分。純前端；mobile-first。

也可當作 [Playgrounds](https://play.samkuo.me/) 的 **SAM**。

## 一鍵開

**[一鍵開 SAM](https://play.samkuo.me/?open=sampot%2Fpg-merge2048&name=%E6%95%B8%E5%AD%97%E5%90%88%E4%BD%B5)**

## 試玩

```bash
npx --yes serve .
```

## 操作

手指滑動或方向鍵移動；相同數字合併加倍。

## 測試

```bash
npx --yes vitest run
```
